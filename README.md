# TWSE Zero-Face Stock Radar (台灣證交所無頭爬蟲與 AI 語意分析實踐)

> **核心箴言**：  
> 「GUI 是人類肉眼妥協的皮囊，Zero-Face 則是讓意圖直達數據本質的進化；最好的介面，就是感覺不到介面。」  
> 「不背語法想流程，先定輸入與輸出；大題化小拆積木，指揮 AI 做驗收。」

本專案為短篇科幻小說《糖衣包裹的引力波》背後真實落地的技術實踐庫。  
透過 Python 實現台灣證券交易所（TWSE）官方 API 的**脫殼直取（Headless / Zero-Face）**，跨越圖形化看盤軟體的繁冗皮囊，提供即時大盤加權指數、個股成交量價、本益比與殖利率分析，並作為後續大語言模型（LLM）金融語意決策架構的可靠數據源。

---

## 🧭 一、核心功能特性

1. **脫殼直取（Pure Zero-Face API）**：
   - 不依賴肥大的網頁渲染器，直接對接 TWSE 官方 JSON 端點（`FMTQIK`、`STOCK_DAY`、`BWIBBU`）。
2. **跨月滑窗自動補齊（Cross-Month Sliding Window）**：
   - 遭遇月初或長假交易天數不足時，程式自動依日曆時間指針向歷史月份倒推拼接（支援跨年至前一年 12 月），確保輸出完整指定天數（預設 10 日）。
3. **終端優雅表格（Tabulate Integration）**：
   - 內建格式化文字表格輸出，一鍵產生清晰易讀的盤面數據。
4. **極端行情微觀診斷（死貓跳 / 斷頭潮識別）**：
   - 可直接對接 AI 語意推理，解析單日暴跌、天量長下影線（帶血籌碼）與縮量急彈（死貓跳）。

## ⚡ 二、快速開始 (Quick Start)

### 1. 安裝環境依賴
```bash
pip install requests tabulate
```

### 2. 常用命令列指令 (CLI)

```bash
# 1. 抓取近期大盤加權指數與成交量價資訊 (-i)
python stocks.py -i

# 2. 抓取台積電 (2330) 近期各日成交量價 (-p 股票代碼)
python stocks.py -p 2330

# 3. 抓取台積電 (2330) 近日殖利率、本益比及股價淨值比 (-v 股票代碼)
python stocks.py -v 2330

# 4. 複合查詢：同時輸出個股成交價量與基本面估值比率
python stocks.py -p 2330 -v 2330
```

## 🧠 四、軟體工程與 AI 財務分析理論

在傳統財務分析中，數值本身是冰冷的；但透過「爬蟲 + AI 語意大腦」，我們能精準彌合**「數值」與「金融語意」的鴻溝（Numeric-Semantic Gap）**：

1. **從「上漲 100 元」到「死貓跳（Dead Cat Bounce）」**：
   - 傳統代碼僅能計算 `2,235 - 2,135 = +100`。
   - AI 語意大腦結合成交量從 11 萬張驟降至 4.5 萬張（-58.5%），立即推導出此為「籌碼真空與空頭回補誘多」，上方 2,300~2,350 元仍有 5,000 億套牢盤，切勿追高。
2. **從「成交 1.32 兆」到「恐慌拋售高潮（Selling Climax）」**：
   - 識別全市場維持率跌破 130% 斷頭潮，並在 2,020 元天量換手中確立去槓桿第一階段的「第一隻腳」。

完整理論架構請參閱：[軟體工程_財務分析學習筆記.md](docs/軟體工程_財務分析學習筆記.md)。
